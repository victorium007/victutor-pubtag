יחידה 1: מבוא ועקרונות יסוד

שאלות רב־ברירה נכון / לא נכון זיהוי סוגיות מאגר ידע חיפוש

30 שאלות במתכונת החלק השני של הבחינה. בוחרים תשובה אחת, הנכונה והמדויקת ביותר. אחרי הבחירה מוצגים הסבר לכל אפשרות והפניה לשיעור.

נענו 0 מתוך 30 נכונות 0

15 טענות על החומר. מסמנים אם הטענה נכונה או לא נכונה, ומקבלים הסבר והפניה לשיעור. כשהטענה אינה נכונה, ההסבר מציג גם את הנוסח הנכון.

נענו 0 מתוך 0 נכונות 0

אירועונים קצרים לתרגול זיהוי סוגיות, כהכנה לשאלות היישום בחלק הראשון של הבחינה. קוראים את האירוע, מסמנים את כל הסוגיות שהוא מעורר, ובודקים. ייתכנו כמה סוגיות נכונות בכל אירוע.

נבדקו 0 מתוך 0 זוהו במלואם 0

סיכום הנלמד בשיעורים 1–3 ובשיעור המקוון הראשון ביסודות דיני חברות, לפי נושאים, עם הפניות לשיעור, לפרק ולחותמת הזמן בהקלטה.

חיפוש מושג, פסק דין (לפי שם) או כלל משפטי במאגר הידע, המסכם את מצגות השיעורים ואת הקלטותיהם. כל תוצאה מפנה לשיעור, לפרק ולחותמת הזמן בהקלטה. החיפוש אינו כולל את שאלות התרגול והאירועים.

כלי עזר לתרגול בלבד. חומרי הלימוד המחייבים הם הסילבוס, השיעורים ופריטי המידע שבאתר הקורס. לשימוש תלמידי הקורס בלבד.
לשיפור הקורס נאסף מידע אנונימי על השימוש במתרגל (כניסות, תשובות וחיפושים), ללא שם או פרט מזהה.
